# AHMAD AIR STRIKE: Android app

Offline 2D arcade flying shooter, packaged with Capacitor.
App name: AHMAD AIR STRIKE · Package: `com.ahmad.airstrike` · Version 1.0.0 · Landscape · Android 8.0+

## Get the APK (no Android Studio needed)
1. Create a free GitHub account and a **new empty repository** (e.g. `ahmad-air-strike`).
2. Upload **everything inside this folder** (including the hidden `.github` folder) to the repository root. On the web: *Add file → Upload files*, drag the contents in, and commit. Make sure `.github/workflows/android-build.yml` ends up at that exact path.
3. Open the **Actions** tab → **Build Android APK**. It starts automatically after the upload. If it doesn’t, click **Run workflow**.
4. Wait about 5 to 10 minutes until the run shows a green tick.
5. Open the finished run and scroll to **Artifacts**. Download **AHMAD-AIR-STRIKE-debug-apk** (a ZIP) and unzip it to get `app-debug.apk`.

## Install on your phone
1. Copy `app-debug.apk` to your phone (USB, Google Drive, WhatsApp to yourself, etc.).
2. Tap the file. If asked, allow **Install unknown apps** for the app you opened it from.
3. Tap **Install**, then **Open**. You can switch off internet: the game is fully offline.
4. If Play Protect warns about an unknown developer, choose **Install anyway** (this is a debug build you made yourself).

## Play
Left joystick moves, **FIRE** shoots, **SPECIAL** unleashes the charged blast. Back button: pauses in a match, steps back in menus, press twice at the main menu to exit.

## If the build fails
Open the failed run, click the red step, and send me the last 30 lines of its log.

## Folder guide
- `www/index.html`: the whole game · `assets/`: icon and splash source art
- `capacitor.config.json`, `package.json`: app settings and dependencies
- `scripts/patch_android.py`: sets landscape, fullscreen and version on the generated project
- `.github/workflows/android-build.yml`: the automatic APK build
- The `android/` folder is generated by the workflow on first run (or by `npx cap add android` locally).

## Build locally (optional)
Needs Node 20 and JDK 17 with the Android SDK:
`npm install && npx cap add android && npx capacitor-assets generate --android && python3 scripts/patch_android.py && npx cap sync android && cd android && ./gradlew assembleDebug`
The APK is at `android/app/build/outputs/apk/debug/app-debug.apk`.
